    PHONE TEST · NOTHING TO BUY

    Test your own phone.
    No spectrometer needed.

    A phone can answer two questions by itself. How stable are its photos from day to day? And do extra lights add independent measurements, or only more numbers?

    WHAT THIS CANNOT SHOW

    This test measures stability and independent measurements. It does not show spectral accuracy, which needs a reference instrument, and it says nothing about identifying fungi.

    1

    Set up

    Fix the phone on a stand in a dark room. Lock focus and exposure if you can. Choose about 30 matte objects with varied colors, and mark where each one sits.

    2

    Change the light

    Photograph each object with the flash, then lit by a laptop or tablet screen showing each color in the light panel. Keep the screen close and in the same place.

    3

    Repeat

    Take 3 photos per object and light, in at least 3 sessions on different days or restarts. Name each file by object, session, light and repeat, like mug_s1_flash_r2.jpg or mug_s1_screen-red_r2.jpg.

    4

    Analyze

    Add the photos below and draw a box over the object, or paste your own table. Photos stay on this computer.

    PHOTOS TO TABLE

    DO EXTRA LIGHTS ADD MEASUREMENTS?

    Independent measurements

    A direction counts only if it is stronger than the strongest direction photo-to-photo noise produces on its own. The count cannot exceed the number of objects minus one.

      CALIBRATION LAB · FIT / TUNE / TEST

      Learn the mapping.
      Hold out the evidence.

      Fit estimated spectra from paired linear RGB and reference reflectance. Tune on validation specimens, then evaluate once on a separate test set. This is the step that needs a spectrometer.

      PAIRED INPUTS

      This lab accepts extracted, normalized linear RGB and 27-band reference spectra. It does not decode DNG or turn an iPhone ProRAW rendering into a verified sensor-linear measurement.
