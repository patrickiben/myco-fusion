Run it yourself

The workbench runs on your computer: the bench, the calibration lab, the validator and the phone test, which needs nothing you don't already own. Photos stay on your machine.

git clone https://github.com/patrickiben/myco-fusion
cd myco-fusion
python3 -m venv .venv
.venv/bin/pip install .
.venv/bin/myco-fusion serve --open
